# Introduction

Welcome to HeadstartWP documentation for the **App Router**! If you are new, we highly recommend reading all the way through [Getting Started](/learn/getting-started/quick-setup/) first.

This documentation covers using HeadstartWP with Next.js App Router (Next.js 15+). If you're using the Pages Router, please refer to the [Pages Router documentation](/learn/pages-router/).
